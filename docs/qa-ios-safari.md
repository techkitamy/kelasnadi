# Checklist Ujian Peranti Sebenar — iPhone / Safari (iOS)

> **Belum diuji pada peranti sebenar.** Ujian automatik hanya Chromium — Safari/iOS
> mempunyai gelagat PWA yang berbeza (tiada `beforeinstallprompt`, audio perlu sentuhan
> pengguna, SW kadang perlukan buka semula app). Tandakan bila anda sudah cuba.
> URL: https://techkitamy.github.io/kelasnadi/ — Versi semasa: semak `version.json`

Peranti: ______________  Versi iOS: ________  Tarikh: __________

## 1. Buka di Safari biasa
- [ ] Buka URL dalam **Safari** (bukan Chrome iOS — PWA install hanya di Safari)
- [ ] Halaman dimuat, kad aliran (Prasekolah/SK/Agama) kelihatan
- [ ] Tiada amaran "bukan sambungan selamat" (HTTPS sah)
- [ ] Butang "Pasang Kelas Nadi" **memang TIDAK muncul** di iOS — ini dijangka
      (iOS tiada `beforeinstallprompt`); guna langkah 2

## 2. Tambah ke Skrin Utama
- [ ] Tekan butang **Kongsi** (petak dengan anak panah naik)
- [ ] Pilih **"Tambah ke Skrin Utama"** (Add to Home Screen)
- [ ] Nama dicadangkan: **Kelas Nadi** → tekan Tambah
- [ ] Ikon muncul di skrin utama (pensel kuning, latar putih/kelabu iOS)
- [ ] Ikon **tidak** kosong/putih

## 3. Buka dalam mod standalone
- [ ] Buka dari ikon skrin utama
- [ ] Tiada bar alamat Safari (mod standalone)
- [ ] Skrin penuh, tiada jalur putih di atas
- [ ] Mula kuiz → boleh jawab, markah naik

## 4. Bunyi (penting di iOS)
- [ ] Mod senyap telefon **MATI** (iOS menyenyapkan audio web bila suis senyap hidup)
- [ ] Jawab betul → ada bunyi
- [ ] **Jika tiada bunyi:** ketik skrin sekali, kemudian jawab lagi (iOS perlukan
      sentuhan pertama sebelum benarkan audio) → catat sama ada bunyi keluar selepas itu
- [ ] Tekan 🔊 → ikon bertukar 🔇 dan bunyi berhenti

## 5. Offline
- [ ] Buka app online sekali (biar penuh dimuat)
- [ ] Keluar app (swipe up) → matikan Wi-Fi + data selular
- [ ] Buka app dari ikon → **app masih terbuka**
- [ ] Jawab kuiz, siapkan, lihat markah
- [ ] Cetak lembaran → di iOS cetakan guna AirPrint atau "Simpan ke Fail" sebagai PDF
- [ ] Hidupkan data → app normal

## 6. Kemas kini app
- [ ] Selepas deploy versi baru: buka app → **bar "Versi baru tersedia"** muncul
- [ ] Tekan **Muat semula** → app dimuat semula sekali, versi baru digunakan
- [ ] Jika bar tidak muncul: tutup app sepenuhnya (swipe) dan buka semula → bar sepatutnya muncul
- [ ] Markah lama kekal selepas kemas kini

## 7. Cetak / simpan PDF
- [ ] **Cetak lembaran** → dialog cetak iOS terbuka
- [ ] Cuba "Simpan ke Fail" → PDF tersimpan dalam app Fail
- [ ] Buka PDF dalam Fail → soalan + skema jawapan lengkap, A4
- [ ] Cuba **Cetak surih** → lembaran garis tiga keluar betul
- [ ] Kongsi PDF ke WhatsApp/iMessage (kongsi dari app Fail)

## 8. Input papan kekunci
- [ ] Soalan taip (Matematik) → papan kekunci muncul, taip nombor, tekan Return/Go
- [ ] Jawapan dinilai tanpa perlu sentuh butang
- [ ] Papan kekunci tidak menutup soalan/butang Semak (iOS suka tolak kandungan ke atas —
      sahkan soalan masih kelihatan atau boleh diskrol)
- [ ] Nama anak: boleh taip, had 30 aksara

## 9. Rendering Jawi (kerap berbeza di iOS)
- [ ] Aliran **Sekolah Agama → Jawi** → mula kuiz
- [ ] Huruf Jawi bersambung betul, tiada kotak ▯
- [ ] Arah kanan-ke-kiri betul
- [ ] Pilihan jawapan Jawi tidak terpotong
- [ ] Bandingkan dengan buku teks — catat perbezaan (iOS guna font Naskh berbeza)

## 10. Putaran skrin
- [ ] Putar ke landscape → susun atur masih boleh guna
- [ ] Tiada teks terpotong pada notch/takuk (safe area)
- [ ] Kembali ke portrait → normal
- [ ] iPad (jika ada): mod tablet, tiada elemen keluar skrin

## 11. Kestabilan
- [ ] Tampal app ke belakang (home) 5 minit → buka semula → kekal bukan skrin putih
- [ ] Markah kekal selepas app ditutup sepenuhnya
- [ ] Padam kemajuan → pengesahan → berjaya
- [ ] Mod peribadi iOS (Private): app masih terbuka (storan mungkin terhad — catat)
