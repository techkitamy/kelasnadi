# Checklist Ujian Peranti Sebenar — Android (Chrome / Samsung Internet)

> **Belum diuji pada peranti sebenar** kecuali dinyatakan. Ujian automatik hanya dijalankan
> pada Chromium headless. Tandakan setiap baris bila anda sendiri sudah cuba.
> URL: https://techkitamy.github.io/kelasnadi/ — Versi app: **3.0.0** (lihat `version.json`)

Peranti diuji: ______________________  Versi Android: __________  Pelayar: ______________  Tarikh: __________

## 1. Pasang PWA
- [ ] Buka URL dalam Chrome Android → tunggu 5 saat
- [ ] Butang **"⬇ Pasang Kelas Nadi"** muncul di bar atas
      *(jika tiada: Chrome menu ⋮ → "Install app" / "Add to Home screen")*
- [ ] Tekan butang → dialog pemasangan muncul → tekan **Install**
- [ ] Tiada mesej ralat selepas pemasangan

## 2. Ikon di skrin utama
- [ ] Ikon **Kelas Nadi** (pensel kuning) muncul di home screen / app drawer
- [ ] Nama di bawah ikon: **Kelas Nadi**
- [ ] Ikon tidak pecah/berpiksel bila dibesarkan

## 3. Buka dalam mod standalone
- [ ] Buka dari ikon → app terbuka **tanpa** bar alamat Chrome
- [ ] Status bar warna kuning (`#ffcf4d`) — atau sekurang-kurangnya tidak putih pelik
- [ ] Butang "back" Android berfungsi (keluar app / kembali ke home)
- [ ] Skrin tidak berputar pelik ketika dibuka (portrait)

## 4. Bunyi
- [ ] Tekan 🔊 (bar atas) → ikon bertukar 🔇
- [ ] Mula kuiz + jawab betul → ada bunyi "ding" (bunyi telefon mesti tidak senyap)
- [ ] Jawab salah → ada bunyi rendah
- [ ] Habis kuiz dengan ≥2 bintang → ada melodi kemenangan
- [ ] Tekan 🔊 semula → bunyi kembali hidup

## 5. Offline
- [ ] Buka app semasa ONLINE sekali (biar penuh dimuat)
- [ ] Tutup app → matikan Wi-Fi + data mudah alih
- [ ] Buka app semula dari ikon → **app masih terbuka**, kad aliran kelihatan
- [ ] Mula kuiz → soalan muncul, boleh jawab
- [ ] Siapkan kuiz → markah keluar
- [ ] Cetak lembaran → browser boleh "Save as PDF" walaupun offline
- [ ] Hidupkan data → app berfungsi normal

## 6. Kemas kini app (versi baru)
- [ ] Apabila dimaklumkan ada versi baru (bar biru "Versi baru Kelas Nadi tersedia"):
      buka app → bar muncul → tekan **Muat semula**
- [ ] App dimuat semula **sekali sahaja** (tidak berulang-ulang)
- [ ] Selepas muat semula: bar hilang, app berfungsi
- [ ] Markah/kemajuan anak **tidak hilang** selepas kemas kini

## 7. Cetak / kongsi PDF
- [ ] Pilih latihan → tekan **Cetak lembaran**
- [ ] Dialog cetak Android terbuka
- [ ] Pilih "Save as PDF" → fail PDF tersimpan
- [ ] Buka PDF: helaian soalan + **skema jawapan** ada, saiz A4, tulisan tidak terpotong
- [ ] Cetak **Cetak surih** → lembaran garis tiga + huruf titik keluar betul
- [ ] Cuba kongsi PDF ke WhatsApp/guru (jika penyimpanan PDF menyokong)

## 8. Input papan kekunci
- [ ] Soalan taip jawapan (Matematik) → papan kekunci muncul
- [ ] Taip nombor → tekan Enter → jawapan dinilai
- [ ] Nama anak di kolum "Nama anak" → boleh taip, had 30 aksara
- [ ] Papan kekunci **tidak** menutup soalan/butang Semak
- [ ] Selepas tutup papan kekunci, susun atur kembali normal

## 9. Rendering Jawi
- [ ] Aliran **Sekolah Agama** → subjek **Jawi** → mula kuiz
- [ ] Huruf Jawi (ا ب ت) kelihatan **bersambung betul**, tidak pecah/kotak
- [ ] Arah tulisan kanan-ke-kiri (huruf pertama di kanan)
- [ ] Pilihan jawapan Jawi tidak terpotong di tepi skrin
- [ ] Bandingkan dengan buku teks — jika ejaan nampak pelik, catat di bawah

## 10. Putaran skrin
- [ ] Putar ke **landscape** → susun atur masih boleh guna, tiada teks terpotong
- [ ] HUD (bintang/streak) tidak menutup soalan semasa skrol
- [ ] Papan kekunci + landscape: butang Semak masih boleh ditekan
- [ ] Putar balik ke portrait → normal

## 11. Perkara lain
- [ ] Selepas refresh (tarik ke bawah), markah kekal
- [ ] Butang **Padam kemajuan** → minta pengesahan → padam berjaya
- [ ] Skrin kecil lama (jika ada) — app masih boleh dibaca
